# 🏙️ Smart Community — IDT Project

**Status: 🟢 Prototype / Academic Project**

**Smart Community** is a lightweight, web-based prototype developed as part of our **Innovation and Design Thinking (IDT)** course, inspired by the **Sustainable Cities and Communities** theme. It acts as a central platform for a neighborhood, helping residents stay informed, access emergency services, report civic problems, and stay connected with their community in one place.

## 📌 Overview

Many everyday civic problems—such as potholes, broken streetlights, garbage, waterlogging, and drainage issues—can go unreported or unresolved because residents lack a simple way to raise and track them.

**Smart Community** addresses this problem through a clean, accessible, and easy-to-use interface. It demonstrates how technology and design thinking can help residents **report, track, and respond to community issues more effectively**.

We followed the basic Design Thinking process of understanding the problem, identifying user needs, brainstorming solutions, and developing a working prototype.

## ✨ Features

* **Community Dashboard** — Location, weather, active issue count, and quick-access options
* **Weather Updates** — Temperature, forecast, and rain alerts
* **Emergency Services** — Nearby hospitals, police stations, helpline numbers, calls, and directions
* **Civic Problem Reporting** — Report issues by category, location, description, and optional photo
* **Complaint Tracking** — Track issues from **Submitted → Verified → In Progress → Resolved**
* **Community Map** — View reported problems using colour-coded markers
* **Municipality Complaint Box** — Submit and track complaints through a simulated workflow
* **Community Announcements** — Updates about road work, water supply, garbage collection, and meetings

## 🚀 Quick Start

1. **Clone or download** this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Explore the dashboard and available features.

No backend, database, or additional installation is required to run the prototype.

## ⚠️ Prototype Limitations

This project is an **academic prototype** and is not intended for real-world municipal use yet.

* Weather, location, map, and emergency-service information may use **sample or simulated data**.
* Complaint submission and tracking use a **simulated workflow** and are not connected to an actual municipality.
* The project does not currently use a backend database or user authentication.
* Emergency-service information should be independently verified before being used in a real emergency.
* Some features are designed to demonstrate the concept rather than provide production-ready functionality.

## 🎯 Project Purpose

Our goal was not only to build a website but to demonstrate how **design thinking and technology can be combined to create practical solutions for real-world community problems**. Through this project, we gained hands-on experience in problem identification, brainstorming, UI design, teamwork, and basic web development.
